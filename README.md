# Interconnect-MP

**Project I: Modeling an Interconnect for a Multi-Processor (MP) System**

This project simulates the behavior of an interconnect in a multiprocessor system, enabling the analysis of cache coherence and communication between multiple processing elements.

##  How to Use

1. Clone or download the repository.
2. Open a terminal and navigate to the project directory.
3. Run the following commands to execute the program:

```bash
cd build
cmake ..
make
./interconnect
